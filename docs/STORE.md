## 詳細説明

```text
LecScribe は、動画を見ながらノートを取るための道具です。講義や解説の動画を再生すると、話の内容と画面を Markdown のノートにまとめます。

■ できること
・タブの音声を録音します（音はそのまま聞こえます）
・画面が切り替わったときだけ動画の画像を保存します。同じ画面が何枚も並びません
・見終わると Mac 上の WhisperKit が日本語で文字起こしし、画像と本文を時間順に並べた notes.md ができます
・ChatGPT（Codex CLI）かローカルの Ollama を使える場合は、話し言葉を書き言葉に整え、要点と見出しを付けられます（任意）

■ すべて Mac の中で処理します
音声・画像・文字起こしは利用者の Mac の中で処理・保存します。開発者のサーバーはなく、利用状況の計測もしません。外に出るのは「ノートを整える」を自分で有効にしたときの文字起こしの本文だけです。

■ 使うには Mac 側の準備が要ります
拡張を入れたあと、パネルに出る 1 行をターミナルに貼ると、Mac に文字起こしのサーバーが入ります（Homebrew、ffmpeg、whisperkit-cli を使います）。Apple Silicon の Mac（macOS 14 以降）が必要です。Windows では動きません。

■ 使う前に
・個人の学習用です。自分が視聴できる動画を見ながら、自分のためのノートを作る道具です。録音・画像・ノートを配布・公開しないでください
・利用するサイトの規約に従ってください。録音や画面の保存を禁じているサイトでは使わないでください
・動画ファイルの取得や、DRM・認証・アクセス制御の回避は行いません。再生中のタブの音と画面を取り込むだけです

ソースコードと使い方: https://github.com/tacamy/lec-scribe
```

## 単一目的（Single purpose）

```text
再生中の動画の音声と画面から、学習用のノート（Markdown）を作ること。
```

## 権限の説明（審査で 1 つずつ聞かれる）

| 権限 | 説明（貼る文） |
|---|---|
| `tabCapture` | 利用者が Start を押したタブの音声を録音するために使います。録音は拡張の内部領域に保存し、Mac 上のローカルサーバーに渡します |
| `activeTab` | Start を押したタブにだけ、動画を見つけて画面の変化を調べるスクリプトを入れるために使います。ほかのタブやサイトにはアクセスしません |
| `scripting` | `activeTab` で許可されたタブに、動画の検出と画面の変化検知のスクリプトを入れるために使います |
| `offscreen` | Manifest V3 では録音（getUserMedia と MediaRecorder）を service worker で行えないため、offscreen document で録音します |
| `sidePanel` | Start / Stop と進み具合、保存済みのノートの一覧を、ページを操作しても閉じないサイドパネルに表示します |
| `storage` | 設定と、録音中の状態、Mac 上のサーバーとの接続用トークンを保存します（Mac の中でだけ使います） |
| `alarms` | サーバーへの送信に失敗したとき、時間を置いて送り直すために使います（service worker は止まることがあるので setTimeout が使えません） |
| ホスト権限 `http://127.0.0.1/*` | 同じ Mac 上のローカルサーバーに録音と画像を送り、進み具合を受け取るためです。ほかのホストには通信しません |

## データ利用の申告（ダッシュボードの質問票）

- 収集・扱うデータの種類（ストアの区分で答える）: **ウェブサイトのコンテンツ**（タブの音声と動画の画面の画像）と **ウェブ履歴**（ページのタイトル・URL・開始時刻を `session.json` に記録するため。ストアの定義「訪れたページの一覧と題名・時刻」に当たる）。「個人的なやり取り」「ユーザーアクティビティ」「個人を特定できる情報」には当たらない
- 用途: 拡張の中核機能（ノート作成）のためだけ。利用者の Mac の中で処理し、開発者には送らない
- 3 つの証明（第三者に売らない / 中核機能と無関係な目的に使わない / 信用力の判断や融資目的に使わない）: すべて該当（はい）

## 必要な画像

| 画像 | サイズ | 用意 |
|---|---|---|
| 拡張のアイコン | 16 / 32 / 48 / 96 / 128 px | `extension/public/icon/` にある（`pnpm icons:make` で `extension/assets/icon.png`（透明背景・正方形）から作る。元画像を差し替えたら実行し直す） |
| ストアのアイコン | 128×128（絵は中央の 96×96、周り 16px は透明。ストアの画像ガイドライン） | `docs/store/icon-128.png`（`pnpm icons:make` が一緒に作る） |
| スクリーンショット | 1280×800 または 640×400、1〜5 枚 | Mac 実機で撮る（下の一覧） |
| プロモーションタイル（任意） | 440×280 | 省略可 |

スクリーンショットの候補（実機で撮る。動画ページは自分の講義ではなく、fixture の `player.html` か、公開されている解説動画を使う）:

1. 動画ページの右にサイドパネルが開き、Video 行に動画が出ている状態
2. 録音中（Capturing）のパネル。スライドの枚数と経過時間が見える
3. できあがった `notes.md` を Markdown ビューアで開いたところ（画像と本文が時間順に並ぶ）
4. 保存済みセッションの一覧（フォルダを開く・やり直す）
