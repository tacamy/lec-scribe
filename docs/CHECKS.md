# 動作確認手順

tabCapture を伴う確認は Mac 実機でしかできないため、Phase ごとの手動確認手順をここにまとめる。結果は本ファイル末尾の「記録」に追記する。

## 共通: 拡張の読み込み

```sh
pnpm install
pnpm build            # extension/dist/chrome-mv3 が生成される
```

1. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」を ON
2. 「パッケージ化されていない拡張機能を読み込む」→ `extension/dist/chrome-mv3` を選択
3. ツールバーの拡張アイコンから LecScribe をピン留め
4. コードを変更したら `pnpm build` → `chrome://extensions` の更新ボタン（↻）

UI の流れ: 動画のタブでツールバーのアイコンをクリックするとポップアップが開く。このクリックがタブへのキャプチャ許可（activeTab）を兼ねるので、`Start` は必ずポップアップから押す。`Start` を押すと右側にサイドパネルが開き、ポップアップは閉じる。パネルはページを操作しても閉じないので、状態の確認と `Stop`、エクスポートはパネルで行う。パネルの `Start` は許可が切れていると失敗する（メッセージが出る）。

エラーは `chrome://extensions` の LecScribe カード内「エラー」と、service worker の DevTools（カード内の「Service Worker」リンク）、パネルの DevTools（パネル内を右クリック →「検証」）で確認する。

## Phase 1: tabCapture + AirPods パススルー

目的: スライド動画を再生中に Start しても、AirPods から音が途切れず、二重にも聞こえないこと（SPEC D-02、Q-12）。

準備: AirPods 等を接続し、macOS の出力デバイスに選ぶ。動画のあるページを開き、動画を再生する。

| # | 操作 | 期待 |
|---|---|---|
| 1 | 動画のタブでツールバーの LecScribe アイコンをクリック | ポップアップに `● Ready` と `Start` ボタンが表示される |
| 2 | `Start` | ポップアップが閉じ、右側にサイドパネルが開く。状態が `● Capturing`、経過時間が進む。`Audio` 行が「録音中」になり、レベルメーターが音声に合わせて動く（「無音」表示にならない） |
| 3 | 聞く | AirPods から動画の音声がそのまま聞こえる。エコー / リバーブのような二重再生になっていない。音量が変わっていない |
| 4 | タブを見る | タブに「共有中」のインジケータ（録画アイコン）が出る |
| 5 | パネルを閉じ、アイコンをクリックしてポップアップを開く | `● Capturing` のまま、経過時間が継続している |
| 6 | 動画を一時停止 → 再開 | 約 1 秒後に「無音」と表示されメーターが 0 になる。再開で動く。経過時間は止まらない（録音を止めない仕様、SPEC §7.3） |
| 7 | `Stop` | 状態が `● Ready` に戻り、フッターに「前回: HH:MM:SS キャプチャ（user）」。動画の音は引き続き AirPods から聞こえる |
| 8 | もう一度 `Start` → `Stop` | 2 回目も同じ挙動 |

異常系:

| # | 操作 | 期待 |
|---|---|---|
| A | `chrome://extensions` など Chrome 内部ページのポップアップで `Start` | 赤いメッセージ「このページはキャプチャできません…」、状態 `● Error`。`Start` で再試行できる |
| B | キャプチャ中に動画のタブを閉じる | パネルが `● Ready` に戻り、前回の理由が `tab closed` |
| C | キャプチャ中に `chrome://extensions` で拡張を更新（↻） | 開き直すと `● Done`、前回の理由が `extension restarted`。セッションは「中断」として残る |
| D | サイドパネルの `Start`（アイコンを押さずに） | 「タブのキャプチャを開始できません…アイコンをクリックして…」のメッセージ。ポップアップからの `Start` で開始できる |

二重に聞こえる場合（パススルー不要な環境）:

パネル内を右クリック →「検証」→ Console で次を実行してから `Start` し直す。

```js
chrome.storage.local.set({ config: { audio: { passthrough: false } } });
```

戻すときは `passthrough: true`。この結果は SPEC D-02 の既定値に反映する。

## Phase 2: 録音（OPFS へ逐次保存 → エクスポート）

目的: 動画の音声が `audio.webm` として残ること。途中で拡張が再起動しても直前のチャンクまで残ること（SPEC D-06）。

| # | 操作 | 期待 |
|---|---|---|
| 1 | 動画ページで `Start` → 2〜3 分待つ | パネルの Audio 行が「録音中 1.2 MB」のように増える（64 kbps なので 1 分あたり約 480 KB） |
| 2 | `Stop` | 状態が `● Done`、Audio 行が「録音完了 00:03:00 / 1.4 MB」。下に「保存済みセッション」が出る |
| 3 | セッションの「エクスポート」 | 状態が `Exporting…` になり数秒で戻る。`~/Downloads/LecScribe/<日時>/` に `audio.webm`、`session.json`、`status.json` ができる |
| 4 | `audio.webm` を Chrome の新しいタブにドラッグ＆ドロップして再生 | 動画の音声が聞こえる。長さが録音時間と一致する（`ffprobe audio.webm` でも確認できる） |
| 5 | もう一度 `Start` → 30 秒待つ → `chrome://extensions` で拡張を更新（↻） | 開き直すとリストに「中断」タグ付きのセッションがあり、エクスポートすると 20〜30 秒分の `audio.webm` が得られる |
| 6 | セッションの「破棄」 | 確認ダイアログのあとリストから消える。`~/Downloads/LecScribe/` に書き出したファイルは残る（破棄は拡張内のデータだけを消す仕様） |

`session.json` には開始時刻（`startedAt`）と設定、`status.json` には終了時刻・バイト数・録音時間が入る。これらは Phase 8 の時刻合わせに使う。

## Phase 3: 動画要素の検出

目的: 動画ページの `<video>`（Brightcove / video.js）が見つかり、録音中にその状態を追えること（SPEC §8.1, §8.2）。

| # | 操作 | 期待 |
|---|---|---|
| 1 | 動画ページで動画を再生した状態でアイコンをクリック | ポップアップの Video 行に「video.js 1280×720 · 再生中」のように出る（Start 前の probe） |
| 2 | `Start` | サイドパネルの Video 行に「video.js 1280×720 · 1x · 再生中 · 00:12:34」。時刻が進む |
| 3 | 動画を一時停止 / 再開 / シーク | Video 行が数秒以内に追従する（一時停止で「一時停止」、シークで時刻が飛ぶ） |
| 4 | 再生速度を 1.5x にする | 警告「再生速度が 1.0x ではありません…」が出る。1.0x に戻すと消える |
| 5 | 別のタブに切り替える | 警告は出ず、Video 行の時刻が進み続ける（Chrome はキャプチャ中のタブを表示扱いのままにして描画も続けるため。Phase 4 で背景中もフレームが撮れるか確認する）。Chrome のウィンドウを最小化した場合の挙動も記録する |
| 6 | 動画のタブ内で別のページへ移動する | 警告「動画ページから移動しました…」。録音は続く（Audio の MB が増える） |
| 7 | 動画のないページ（例: ニュースサイト）で `Start` | Video 行「動画なし（音声のみ）」と警告「このページには動画が見つかりません…」。録音は動く |
| 8 | `Stop` | 通常どおり `● Done` |

任意: 動画ページの DevTools Console で `document.querySelector('video').mediaKeys` が `null` なら DRM なし（警告 DRM は出ない）。`taintFree` の判定結果はサイドパネルでは見えないが、警告「この動画からはスライド画像を取得できません」が出なければ canvas に描ける（Phase 4 の前提）。

## Phase 4: フレーム取得

目的: `<video>` を canvas に描いた画像が動画のネイティブ解像度で保存され、プレイヤー UI やカーソルが映らないこと（SPEC D-03, §8.3）。変化検知は Phase 5 なので、ここでは開始時の 1 枚とパネルの「スクショを保存」で確認する。

| # | 操作 | 期待 |
|---|---|---|
| 1 | 動画ページで `Start` | サイドパネルの Slides 行が「1 枚（最終 00:12:34）」になる（開始時の自動保存） |
| 2 | スライドが切り替わったところで「スクショを保存」 | 緑のメッセージ「slide_002.png を保存しました（1280×720、…）」。Slides 行が 2 枚になる |
| 3 | 別のタブを表示したまま、サイドパネルの「スクショを保存」 | 保存できる。あとで見たとき、その時点の映像が写っている（真っ黒や古いフレームでない） |
| 4 | 動画を全画面にして戻す、ウィンドウを小さくする | どちらの状態でも「スクショを保存」が同じ解像度で保存される（表示サイズに依存しない） |
| 5 | `Stop` → エクスポート | `~/Downloads/LecScribe/<日時>/slides/slide_001.png …` と `slides.json` ができる |
| 6 | 画像を開く | 動画の映像だけが写り、再生バー・カーソル・ページの周辺は映っていない。解像度が `1280×720` などネイティブ値 |
| 7 | `slides.json` を開く | 各要素に `videoTime`（動画内の秒）、`t`（録音開始からの秒）、`reason`（initial / manual）が入っている |

うまくいかない場合: 「この動画は canvas に描けないため…」が出たら tainted（Phase 4 の前提が崩れるので報告してほしい）。「動画がまだ読み込まれていません」は再生を始めてから押す。

## Phase 5: 変化検知

目的: スライドが切り替わったときだけ自動保存され、講師のワイプや小さな動きでは保存されないこと（SPEC §9）。

| # | 操作 | 期待 |
|---|---|---|
| 1 | 動画を 10〜15 分そのまま視聴する | Slides 行の枚数が、スライドの切り替わりに合わせて増える。切り替えから 1〜2 秒後に増える |
| 2 | Video 行の「変化 x.x%」を見る | 何も変わっていないとき 1% 未満。スライドが切り替わった直後は数% 以上 |
| 3 | 講師だけが動いている場面 | 枚数が増えない |
| 4 | 同じレイアウトで文字だけ変わるスライド | 増える（見逃したらその時刻を記録して報告。閾値調整の材料） |
| 4b | 保存されるたびに動画の右下にサムネイルだけのトーストが約 2.5 秒出る。全画面でも出る | 手動保存も同じ表示 |
| 4h | まったく同じ画像が 2 枚並ばない | `notes.md` に同じ画像が続かない。`scenes.json` に `reason: identical` として残る |
| 4g | 映像中心の動画を文字起こしする | `notes.md` には同じ場面の画像が 1 枚だけ載る。`.lecscribe/scenes.json` に外した画像と理由（`sameSceneAs` / `colorMatch`）がある。`slides/` には全部残っている |
| 4f | 被写体を映している場面（スライドではない映像）が続く | 被写体が動いただけでは撮られない。場面が変わったときだけ増える |
| 4e | 講師のワイプ（顔出しの小窓）で先生が動く。スライドは変えない | キャプチャされない（トーストが出ない）。数分見ていて増えないこと |
| 4d | スライドの本文が少しだけ変わる（1 行増える、数語が変わる） | 新しいスライドとしては保存されず、次のスライドに移った瞬間に画像が最後の状態で上書きされる（`slides.json` の `updated: true`）。講師のワイプが動いただけでは上書きされない |
| 4c | 文字が 1 行ずつ出るスライド | 切り替わり直後に保存されたあと、次のスライドに移った瞬間にもう一度トーストが出て、`slides/slide_N.png` が全部出た状態になる。`slides.json` の `updated: true` |
| 5 | 一時停止 → 再開、シーク | 同じ画面に戻った場合は増えない。別のスライドに飛んだ場合は増える |
| 6 | `Stop` → エクスポート → `slides/` を見る | 枚数がスライド数とほぼ一致し、同じスライドの重複がない（あれば何枚か報告） |

報告してほしいこと: 動画のスライド数（目視）と保存枚数、見逃し・重複があればその時刻。`slides.json` の `reason` が `change` のものが自動保存分。

## Phase 6: タイムライン記録

目的: 一時停止・シーク・速度変更を含む視聴の履歴が `timeline.json` に残り、録音時刻から動画時刻を復元できること（SPEC §10）。

| # | 操作 | 期待 |
|---|---|---|
| 1 | `Start` → 数分視聴する間に、一時停止 → 再開、10 秒戻す、再生速度を 1.5x にして 1.0x に戻す | パネルの表示は変わらない（速度変更中は警告が出る） |
| 2 | `Stop` → エクスポート | `timeline.json` ができる |
| 3 | `timeline.json` を開く | 先頭が `start`、末尾が `stop`。操作した順に `pause` / `play` / `seeked` / `ratechange` が並び、`videoTime` が操作時の動画の時刻、`t` が録音開始からの秒。再生中は 10 秒ごとに `tick` |
| 4 | `slides.json` と見比べる | 各スライドの `t` から timeline で動画時刻を求めると `videoTime` と一致する（例: 一時停止中に手動保存したスライドの `videoTime` は停止位置のまま） |

## Phase 7: ローカルサーバーと WhisperKit

目的: Stop 後に録音がサーバーへ送られ、`~/LecScribe/<日時>_<タイトル>/` に日本語の文字起こし（SRT / VTT / TXT / JSON）ができること（SPEC §12, §13）。

準備:

```sh
brew install whisperkit-cli ffmpeg
pnpm --filter @lec-scribe/server start
```

初回は `large-v3` モデル（数 GB）のダウンロードに時間がかかる。サーバーはターミナルを開いたままにするか、`pnpm --filter @lec-scribe/server agent:install` で常駐させる（README「サーバーの常駐化」）。常駐後にサーバーのコードを更新したら `agent:restart`。

| # | 操作 | 期待 |
|---|---|---|
| 1 | ポップアップに出る「このMacと接続」（設定画面にもある）→ Mac に出るダイアログで「許可」→ 設定画面の接続テスト | ダイアログに拡張名と ID が出る。「接続しました」と出て、接続テストは「承認: 済み / whisperkit-cli: あり / ffmpeg: あり」。`~/.lec-scribe/trusted.json` に拡張 ID とトークンが書かれる |
| 2 | 動画を 2〜3 分録音して `Stop` | 状態が `Uploading` → `Transcribing` と進み（末尾の点が 1 文字ずつ増える）、Server 行に「送信中 xx%」→「文字起こし中 · 経過時間」 |
| 3 | 待つ | 状態が `● Done`、Server 行が「完了 · /Users/…/LecScribe/…」。サーバーのターミナルにも進捗が出る |
| 4 | 出力フォルダを開く | 見えるのは `notes.md` と `slides/` だけ。Finder で Cmd+Shift+. を押すと `.lecscribe/` が見え、中に `audio.webm`、`transcript.json` / `.srt` / `.vtt` / `.txt`、`lecture.md`、`slides.json`、`timeline.json`、`session.json`、`pipeline.json` |
| 5 | `.lecscribe/transcript.srt` を開く | 日本語の文字起こしが動画時刻で並んでいる（一時停止・シークがあっても動画の位置に合う） |
| 6 | サーバーを止めた状態で録音 → `Stop` | 警告「ローカルサーバーに接続できません」。セッションは残り、サーバー起動後に一覧の「送信」で文字起こしできる |
| 7 | 拡張を更新（↻）した直後に「送信」 | 文字起こしが動く（再送でサーバー側は上書き） |
| 8 | 文字起こし中に次の動画で `Start` → 数分録音して `Stop` | 録音は普通にできる（Server 行に前の処理の段階が出続ける）。Stop 後は Server 行に「送信待ち 1 件」。前の処理が終わると自動で送られ、順に文字起こしされる |
| 8b | 文字起こし中に一覧の別のセッションで「やり直す」 | ボタンは押せて、その行に「送信待ち」のタグ、Server 行に「送信待ち N 件」。他の行の「やり直す」も押せたまま。前の処理が終わると順に送られる |
| 9 | 文字起こし中に一覧のそのセッションの「破棄」 | 確認のあと処理が止まり（サーバーのログに cancelled）、`~/LecScribe/` のフォルダと拡張内の録音が消える。送信待ちがあれば次が始まる |

処理時間の目安と精度（`large-v3` と `large-v3_turbo` の比較）は結果欄に記録する。

## Phase 8: 統合（lecture.md）

目的: スライドごとに画像とその間の発話が並んだノートができること（SPEC §13.4, D-14）。

| # | 操作 | 期待 |
|---|---|---|
| 1 | 動画を 10 分ほど録音して `Stop`、文字起こし完了を待つ | 出力フォルダに `notes.md` ができる（`--llm` なしなら文字起こしそのまま。同じ内容の `lecture.md` が `.lecscribe/` にもある） |
| 2 | `notes.md` を Markdown ビューア（VS Code のプレビューなど）で開く | 節見出しはなく、スライド画像 → そのスライドの間に話された内容（句点ごとに改行）が `---` で区切られて並ぶ |
| 3 | 画像と本文を見比べる | 本文がそのスライドの話になっている。切り替え直後の発話が前のスライドに混ざる場合はその時刻を報告（自動検知分は 1.5 秒早く始まったとみなして割り当てている） |
| 4 | `.lecscribe/transcript.json` を開く | 各区間に `slide` が入っている（スライド前の区間にはない） |

## Phase 9: ノート作成（notes.md）

目的: 話し言葉の文字起こしを書き言葉に整え、節ごとの要点が付いた `notes.md` ができること（SPEC §13.5）。

準備（`codex exec` を使う場合）:

```sh
brew install --cask codex
codex login
codex exec "こんにちは、と返答して"     # 返答が来れば OK
```

常駐サーバーに設定を渡す（環境変数は登録時に plist へ書き込まれる）:

```sh
LEC_SCRIBE_LLM=codex pnpm --filter @lec-scribe/server agent:install
```

| # | 操作 | 期待 |
|---|---|---|
| 0 | 拡張の設定画面を開く | 「ノート作成」に今の状態が出る。無効なら `bash ~/LecScribe-app/enable-notes.sh` がコピーボタン付きで出る |
| 1b | 続けてもう一度「やり直す」 | LLM を呼ばずに終わる（ログに「前回のノートを使い回します」、`pipeline.json` に `notesReused: true`）。数秒で完了する |
| 1b | 続けてもう一度「やり直す」 | LLM を呼ばずに終わる（ログに「前回のノートを使い回します」、`pipeline.json` に `notesReused: true`）。数秒で完了する |
| 1 | 文字起こし済みのセッションで「やり直す」 | 文字起こしは飛ばされ（ログに「transcript を再利用」）、Server 行が「ノート作成中」を経て数分で完了する（ログに `batch n/m` のあと `outline` が 1 回出る） |
| 2 | 出力フォルダを開く | `notes.md` が整えた版に置き換わっている。文字起こしそのままの `lecture.md` は `.lecscribe/` に残っている |
| 3 | `notes.md` を開く | 冒頭に「全体の要点」。本文は話題ごとの見出しと「要点」で区切られ、その中にスライド画像とフィラーの取れた本文が並ぶ。見出しの区切りが内容に合っている（画面が細かく変わる操作デモでも話題単位になっている）。内容が変わっていない（要約・補足されていない） |
| 4 | `pipeline.json` を見る | `result.notes: true`。`notesError` があれば枠切れなどでその節が文字起こしのまま |

## 残っている実機確認（2026-09-09 時点）

smoke テストでは通っているが、Mac 実機ではまだ確認・記録していないもの。確認したら「記録」に追記する。
