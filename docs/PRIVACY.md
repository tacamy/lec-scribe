# LecScribe プライバシーポリシー

最終更新: 2026-09-24（[English](PRIVACY.en.md)）

LecScribe は、動画を見ながらノートを取るための Chrome 拡張と、それを受け取る Mac 上のローカルサーバーです。**録音・画像・文字起こし・ノートは、すべて利用者自身の Mac の中で処理し、保存します。** 開発者は利用者のデータを受け取るサーバーを運営しておらず、利用状況の計測（テレメトリ・解析）も行いません。

## 扱うデータ

| データ | 内容 | 保存場所 |
|---|---|---|
| タブの音声 | 利用者が Start を押したタブで再生されている音声の録音 | 録音中は Chrome 拡張の内部領域（OPFS）。Stop 後に同じ Mac 上のサーバーへ渡し、`~/LecScribe/` に保存 |
| 動画の画面 | 画面が切り替わったとき、または利用者が「今の画面を手動で保存」を押したときの、動画領域の画像 | 同上 |
| ページのタイトルと URL | どの動画のノートかを記録するため | 同上（`session.json`。フォルダ名にタイトルを使う） |
| 文字起こしとノート | Mac 上の WhisperKit が作る文字起こしと、それを並べたノート | `~/LecScribe/` |
| 設定と接続用のトークン | 拡張の設定値と、Mac 上のサーバーとの接続に使うトークン | Chrome の拡張用ストレージ（`chrome.storage.local`）。トークンは同じ Mac の中でだけ使う |

これらは利用者が「削除」を押すか、フォルダを消すまで Mac に残ります。一覧の「削除」は、拡張の内部領域と `~/LecScribe/` の両方から消します。

## 外部への送信

- **Chrome 拡張は、同じ Mac 上のサーバー（`127.0.0.1`）以外とは通信しません。**
- Mac 上のサーバーが外部に接続するのは次の場合だけです。
  1. インストール時に、Homebrew とそのパッケージ（ffmpeg、whisperkit-cli、Node.js、git。ノート整形を有効にするときは Codex CLI）を Homebrew の配布元から取得する
  2. インストール時と起動時に、新しい版があるかを GitHub で確かめ、あれば取得する（HTTPS の `git fetch`。利用者のデータは含まない）
  3. 初回の文字起こしで、WhisperKit のモデル（`whisperkit-cli`）を配布元（Hugging Face）から取得する
  4. **利用者が「ノートを整える」を有効にした場合に限り**、文字起こしの本文を、利用者自身が設定した ChatGPT（Codex CLI 経由）または OpenAI API に送ります。音声・画像・ページの URL は送りません。ローカルの Ollama を選んだ場合は何も送りません
- 開発者に送られるデータはありません。

## 第三者

- 拡張の配布: Google（Chrome ウェブストア）。ストアの利用状況は Google のポリシーに従います
- サーバーと依存するソフトの取得: Homebrew、GitHub
- ノートを整える機能（任意）: OpenAI（ChatGPT / OpenAI API）。送られる文字起こしの扱いは OpenAI のポリシーに従います
